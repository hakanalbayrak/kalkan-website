# Self-hosted web fonts

`inter-tr-variable.woff2` and `plus-jakarta-sans-tr-variable.woff2` are
performance subsets generated from the official Google Fonts sources. They
contain Basic Latin, Latin Extended characters used by Turkish, common
punctuation, currency symbols and arrows.

- Inter source: https://github.com/google/fonts/tree/main/ofl/inter
- Plus Jakarta Sans source: https://github.com/google/fonts/tree/main/ofl/plusjakartasans
- License: SIL Open Font License 1.1 (see each upstream directory)

The older `latin` and `latin-ext` files remain for rollback compatibility but
are no longer requested by the theme.
